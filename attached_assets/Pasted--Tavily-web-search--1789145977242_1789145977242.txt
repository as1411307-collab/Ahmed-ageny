اعتبر اختبار Tavily الأساسي ناجحًا، لكن لا تضف أي أداة جديدة الآن.

طوّر web_search الحالي إلى طبقة بحث احترافية باسم research_search مع إبقاء web_search للبحث السريع.

المطلوب:

1. افهم نوع الاستعلام قبل البحث:
   - official / primary sources
   - current news
   - academic / scientific
   - technical
   - general web
   - social/community
   - legal/government

2. إذا طلب المستخدم official أو source رسمي:
   يجب إعطاء الأولوية للموقع الرسمي أو المستودع الرسمي أو الجهة الحكومية/الأكاديمية الأصلية.
   لا تعتبر المهمة ناجحة إذا كانت كل المصادر ثانوية مع وجود مصدر أولي متاح.

3. research_search يجب ألا يعتمد على استعلام واحد فقط.
   فكك السؤال عند الحاجة إلى عدة استعلامات مترابطة، ثم ادمج النتائج وأزل التكرار.

4. وسّع البحث عالميًا.
   لا تحصر النتائج بدولة أو لغة واحدة.
   استخدم استعلامات بلغات إضافية عندما يكون ذلك مفيدًا للموضوع، مع الحفاظ على الاستعلام الأصلي.

5. في الوضع العميق:
   اجلب حتى 10-12 نتيجة مرشحة، ثم اختر أفضل المصادر فعليًا.
   افتح الصفحات واقرأ محتواها الحقيقي، وليس snippets محرك البحث فقط.

6. رتّب المصادر بحسب:
   - المصدر الأولي/الرسمي
   - الصلة المباشرة بالسؤال
   - الحداثة عندما تكون مهمة
   - الموثوقية
   - الاستقلال عن بقية المصادر

7. لا تملأ النتائج بمصادر متعددة تنسخ نفس الخبر أو نفس المصدر الأصلي.

8. لكل ادعاء مهم:
   حاول التحقق منه من مصدر أولي أو من مصدرين مستقلين.
   إذا تعارضت المصادر، أظهر التعارض بدل اختيار أحدها بصمت.

9. أرجع لكل مصدر:
   title
   url
   domain
   published_at إن توفر
   source_type
   primary_or_secondary
   النص الداعم أو المقتطف المستخرج

10. أضف وضعين فقط للمستخدم:
    FAST = بحث سريع قليل التكلفة
    DEEP = بحث متعدد الاستعلامات والمصادر والتحقق

11. لا تضف Exa أو Brave أو أي API آخر الآن.
    استخدم Tavily الحالي أولًا وأثبت حدود ما يستطيع فعله.

12. لا تغيّر معمارية المشروع ولا تنشر التطبيق.

بعد التنفيذ نفّذ اختبارين حقيقيين:

TEST A:
"official Python MCP Streamable HTTP documentation"
المتوقع: مصدر رسمي من modelcontextprotocol/python-sdk أو الوثائق الرسمية ضمن النتائج الأولى.

TEST B:
سؤال حديث فيه معلومة متنازع عليها، ونفّذ DEEP mode مع عدة مصادر مستقلة وبيّن أي اختلاف بينها.

أعطني في النهاية:
- الملفات المعدلة
- ما أضيف فعليًا
- نتائج الاختبارين
- عدد طلبات Tavily المستخدمة
- أي حدود أو فشل ظهر
ولا تقل نجح إلا إذا تم تشغيل الاختبارات فعليًا.
