==================================================
2. افحص الأدوات المسجلة فعليًا
==================================================

اعرض كل tools المتاحة حاليًا للـagent.

لكل tool:
- name
- implementation location
- purpose
- scope
- whether currently registered
- whether actually callable
- dependencies
- required secret/API key
- current status

افحص خصوصًا:
- PydanticAI tools
- MCP tools
- skill_tools
- any dynamically registered tools

==================================================
3. افحص MCP
==================================================

اعمل inventory لكل MCP capability الموجودة حاليًا.

أريد معرفة:
- MCP servers/configuration الموجودة
- tools exposed
- resources إن وجدت
- search/retrieval capabilities
- whether enabled or dormant
- whether they duplicate existing Tavily/Search Fabric functionality

لا تضف MCP server جديد.

==================================================
4. افحص dependencies
==================================================

راجع Python وNode dependencies والـlockfiles بحثًا عن packages قد توفر أصلًا:

- search APIs
- crawling
- scraping
- web/page retrieval
- feeds
- GitHub
- academic APIs
- browser automation
- document/web extraction

فرّق بين:
DIRECT
TRANSITIVE

ولا تعتبر مجرد وجود package دليلًا أن capability مستخدمة.

==================================================
5. افحص configuration
==================================================

راجع أسماء environment variables/configuration فقط.

لا تعرض قيم أي secret.

ابحث عن configuration تشير إلى providers أو integrations موجودة سابقًا مثل:

*_API_KEY
*_TOKEN
*_BASE_URL
*_SEARCH_*
*_MCP_*

اذكر أسماء المتغيرات فقط وحالتها:
CONFIGURED / NOT_CONFIGURED
إذا كان بالإمكان تحديد ذلك بأمان.

لا تطبع أي secret value.

==================================================
6. افحص الأدوات القديمة أو غير المستخدمة
==================================================

ابحث عن:
- dead code
- disabled adapters
- previous experiments
- unused search wrappers
- dormant integrations
- duplicate search implementations
- tools موجودة ولكن غير مسجلة للagent

لا تحذفها.

==================================================
7. افحص قدرات Tavily الحالية بدقة
==================================================

- result count controls
- domains

- أي capabilities أخرى مستخدمة أو موجودة

حدد الفرق بين:
IMPLEMENTED

SUPPORTED_BY_PROVIDER_BUT_NOT_IMPLEMENTED

8. افحص Search Fabric الجديد
==================================================

- هل توجد duplication؟
- هل أنشأنا parallel search path غير ضروري؟
- هل web_search القديم ما زال entry point الأساسي؟
- كيف يصل agent فعليًا إلى Search Fabric؟

إذا وجدت duplication:
لا تصلحه الآن.
فقط وثقه.
